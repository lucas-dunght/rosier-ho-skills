# Vertical Social Card & Carousel Style Gallery (`rs-media-product-photo-studio`)

> Curated 3:4 vertical visual styles optimized for Instagram, Threads, Facebook, TikTok Photo Mode, and Xiaohongshu. Core principle: **Describe the emotional mood, tactile texture, and editorial reference rather than micromanaging pixel coordinates.** Always specify clean Vietnamese typography with accurate diacritics.

## Tier 1: Strongly Recommended

### 1. Clean Infographic (Infographic Tối Giản Sắc Nét)

**One-liner**: Crisp off-white background + structured modular cards + bold color accents; the ultimate style for save-worthy tutorials and comparisons.

**Base Style Prompt:**
```text
VISUAL REFERENCE: Clean data dashboard meets editorial infographic from Monocle magazine.
CANVAS: 3:4 portrait aspect ratio, 1080x1440 pixels, high quality rendering.
COLOR SYSTEM: Crisp warm white (#F5F5F5) background, tech blue (#4A90D9) as primary accent, warm orange (#FF6B35) for emphasis, charcoal (#333333) for text. Clean, breathable, professional.
TEXT RENDERING: Clear typographic hierarchy in Vietnamese with accurate diacritics (dấu tiếng Việt) · large bold heading, medium subheading, structured body labels. Information is king.
```

**Cover Prompt Example:**
```text
Create a clean infographic-style vertical social media cover (3:4 portrait aspect ratio, 1080x1440 pixels).

[Base Style]

DESIGN INTENT: The viewer should immediately think "This looks structured and super useful, I need to bookmark this."

TEXT TO RENDER (Vietnamese text with accurate diacritics / dấu tiếng Việt):
- Title: "Claude vs GPT"
- Subtitle: "So sánh thực chiến sau 30 ngày"

Structured layout with clear visual hierarchy. Data feels trustworthy and well-organized. Do NOT include any personal signature or watermark.
```

**Best For**: Tutorials, head-to-head comparisons, benchmarks, tool roundups.
**Note**: Keep information density high and structured without visual clutter.

## Multi-Slide Carousel Consistency Rules

1. **Shared Base Style** · All slides in the same carousel must share the exact same Base Style Prompt.
2. **Locked Color Palette** · Use at most 4 colors across the entire set.
3. **Consistent Structural Grid** · Keep header placement, margins, and typography scale consistent across inner slides.
4. **Cover Slide Maximum Impact** · Slide 1 carries the strongest visual hook and largest hero text.
5. **Final Slide CTA** · Reserve the last slide for a summary recap and engagement prompt (Save / Share / Follow).
6. **Slide Numbering** · Include sequential badges (`01`, `02`, `03`...) on step-by-step carousels.

## Prompt Anti-Patterns to Avoid

| Anti-Pattern | Why It Fails | Better Alternative |
|---|---|---|
| `"professional modern clean"` | Produces generic, forgettable AI stock art | Cite concrete editorial references (*Monocle*, *Kinfolk*, *Wired*, notebook sketch) |
| Specifying exact pixel coordinates (`x=120, y=340`) | Image diffusion models ignore pixel coordinates | Describe visual hierarchy (`3x larger hero word in center`) |
| Describing wide landscape scenes | Causes the model to drift away from vertical composition | Explicitly declare `3:4 portrait aspect ratio, 1080x1440 pixels` |
| Packing 25+ Vietnamese words into a single AI prompt | High probability of garbled Vietnamese diacritics | Keep AI text to `<= 6-8 words` for headlines, or use **Path A (HTML -> Playwright)** for text-dense slides |
| Mixing different visual styles between cover and inner slides | Makes the carousel look disjointed | Reuse the exact same Base Style block across all slides |
